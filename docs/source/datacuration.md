# Data curation on COSMA

COSMA offers many facilities and options for data curation, data sharing, data transfer and data access.

## Data transfer

The [data transfer pages](data.md) offer advice on moving data to other systems

## Data sharing

There are several optinos for making data accessible for download by other researchers, please contact us if you wish to set something up.

- Web download
- S3 exports
- [StorJ](storj.md) sharing

## Database access

If you need to arrange database access or a web frontend for your data, please contact us.

## Long-term storage

We can potentially offer long-term storage (with caveats) for some COSMA data.  Please contact us to discuss your requirements.
