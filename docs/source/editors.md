# Editing code on COSMA

There is no particular editor you should use.  However, here are a few notable ones.

- [Emacs](emacs.md) (our recommendation!)
- [Vi/Vim](vi.md)
- [Nano](nano.md)
- [VS Code](vscode.md)
- [Ed](ed.md)

Although not an editor, [tmux](tmux.md) is a very useful tool for multiplexing your terminal, i.e. enabling you to switch rapidly between an editor and the commandline without needing to open multiple SSH connections.

It is also worth noting that many terminal editors support multiple buffers, i.e. you can have multiple files open at once, and switch between them.
